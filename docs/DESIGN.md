# АРТА: Башня — проектный документ

Игра для Android (альбомная ориентация). Игрок — единственный оператор тяжёлой береговой башни
батареи «Утёс». Цель не видна: разведка сообщает её координаты. Игрок сам проходит всю процедуру
выстрела, переходя между **постами** башни и работая с механическими органами управления:
маховиками, барабанными счётчиками, рычагами, лампами.

Это оригинальная игра в жанре «симулятор башенного орудия». Мы **не копируем** чужие игры:
своё оформление, свои названия, своя компоновка постов, свои задания.

## 1. Игровой цикл (процедура выстрела)

| № | Пост (id) | Что делает игрок |
|---|-----------|------------------|
| 1 | **ПЛАНШЕТ** (`plot`) | Ставит фишку цели на карту по координатам из донесения, наводит на неё алидаду (поворотную линейку от батареи), считывает **пеленг** (°) и **дальность** (км), жмёт «ЗАПИСАТЬ». |
| 2 | **ВЫЧИСЛИТЕЛЬ** (`computer`) | Маховиком набирает дальность на счётчике, переключателем выбирает **заряд** 1…6 (лампы показывают, какие заряды достают), тянет рычаг «ВЫЧИСЛИТЬ» — счётчик выдаёт **угол возвышения** и время полёта. |
| 3 | **ЗАРЯЖАНИЕ** (`loading`) | Ствол должен быть на угле заряжания (≤ 3°). Открыть затвор → подать снаряд (ОФ/ББ) → дослать → подать нужное число зарядов → закрыть затвор. |
| 4 | **ПОВОРОТ** (`traverse`) | Снять стопор, рычагом привода и маховиком точной наводки выставить пеленг башни, поставить стопор. |
| 5 | **ПОДЪЁМ** (`elevation`) | Маховиком выставить угол возвышения ствола, равный вычисленному. |
| 6 | **ОГОНЬ** (`fire`) | Табло готовности (лампы), взвести цепь стрельбы, дёрнуть спуск. Секундомер полёта, телеграфная лента с докладом корректировщика. |

После разрыва корректировщик докладывает отклонение («недолёт 240, влево 60») — игрок вносит
поправки в дальность/пеленг и повторяет. Цели бывают движущимися (нужно упреждение) и
бронированными (нужен ББ). Противник может обстреливать батарею — падает «прочность».

## 2. Технологии и структура

- Three.js (npm `three`), сборка esbuild в один классический скрипт `app.js` (IIFE, без ES-модулей в рантайме —
  страница открывается по `file://` в Android WebView).
- Исходники: `web/src/**` (ES-модули). Боевая сборка: `cd web && node build.mjs` → `app/src/main/assets/www/`.
- Стенд разработки: `node build.mjs --dev <name>` собирает `web/src/dev/<name>.js` в `web/.dev/<name>/`
  (там же генерируется `index.html` с `<canvas id="stage">`).
- Снимок экрана: `node tools/shot.cjs .dev/<name> <out.png> [--w 844 --h 390 --dpr 2 --wait 1500 --eval "js"]`
  (headless Chromium + WebGL через SwiftShader; печатает ошибки страницы).
- Опорные размеры экрана для проверки: **844×390** (20:9-подобный телефон) и **740×416** (16:9), альбомная.

```
web/src/
  main.js                 — точка входа (оболочка)
  engine/                 — рендер, комната, камера, ввод, материалы, звук, органы управления
  game/                   — чистая логика без THREE (баллистика, задания, состояние) — тестируется в node
  stations/<id>.js        — посты
  ui/                     — DOM-оболочка: меню, HUD, блокнот, итоги
  dev/                    — стенды разработки
web/static/               — index.html, style.css боевой сборки
```

## 3. Оформление (обязательно для всех)

Образ: тесная стальная башня береговой батареи, середина XX века. Тёплый свет ламп в решётках,
крашеный металл с потёртостями, эмалевые шильдики, бакелит. Палитра (hex):

| Назначение | Цвет |
|---|---|
| Панели пультов, кожухи | сине-серая сталь `#3d4a57` (тёмная `#2b343d`) |
| Силовой набор, стены | `#1d2329`, пол `#15191d` |
| Маховики, рукояти приводов | охра `#d39a1e` (эмаль), рукоятки — чёрный бакелит `#16171a` |
| Оправы приборов | никель `#b9c0c4` |
| Циферблаты, шкалы | слоновая кость `#e8e0c8`, деления `#1a1a1a`, красная зона `#c0392b` |
| Трубопроводы | медь `#b06a3c`, сталь `#59636d` |
| Лампы | зелёная `#4be36a`, красная `#ff4a3a`, янтарная `#ffb347`, белая `#fff3d6` |
| Шильдики | чёрный анодированный фон `#111316`, гравировка `#e8e0c8`; предупреждающие — красный фон `#8f1d14` |
| Цифры счётчиков | белые `#f2efe6` на чёрных барабанах `#0c0d0e` |

Правила:
- Все надписи — **на русском, ПРОПИСНЫМИ**, шрифт Oswald (встроен, кириллица) — см. `engine/fonts`.
- Никаких красных маховиков на бирюзовых пультах и латунных оправ — это чужой образ. Наш: охра на сине-серой стали, никель.
- Без теней в реальном времени. Свет: полусферический + ключевой свет, который движок сам держит у текущего поста,
  + не более двух заполняющих в комнате. **Посты не добавляют источников света** — только эмиссивные материалы и
  спрайты свечения (`ui.lamp`).
- В сцене задана карта окружения (низкая интенсивность), чтобы металл не был чёрным.
- Текстуры ≤ 512 px (карта планшета — до 2048). Не плодить материалы: брать из `mat.*`.
- Производительность: цель — 60 к/с на среднем телефоне. Декор объединять, пост ≤ ~120 вызовов отрисовки.

## 4. Пространство

Круглое помещение башни: радиус стен 3.55 м, потолок 2.6 м. Восемь постов стоят по кольцу радиуса
**2.6 м** через 45°, лицом к центру. Порядок по часовой стрелке (вид сверху): `plot`, `computer`, `loading`,
`traverse`, `elevation`, `fire`, `observe`, `aa`.

**Локальная система координат поста** (в ней пост строит свою `group`):
- начало — на полу под центром поста; `+Y` вверх; `+Z` — к центру помещения (к игроку); `+X` — вправо для игрока;
- лицевая плоскость пульта — около `z = 0`; за ней до стены ~0.9 м (стена на `z ≈ −0.95`);
- габарит поста: ширина ≤ 1.8 м (|x| ≤ 0.9), высота ≤ 2.4 м; перед пультом (`z > 0.35`) ничего не ставить.

Движок сам ставит и поворачивает `group` поста на кольце. Камера задаётся постом в локальных координатах:
`camera: { position:[x,y,z], target:[x,y,z], fov }` (вертикальный угол; по умолчанию позиция `[0,1.42,1.25]`,
цель `[0,1.08,0]`, `fov 46`).

**Зона управления.** Экран телефона — от 16:9 до 20:9; сверху 40 px и снизу 56 px (из 390) закрыты DOM-панелями HUD.
Все интерактивные элементы и важные приборы должны помещаться в кадр 16:9 с запасом: при камере по умолчанию
это прямоугольник |x| ≤ 0.85, 0.74 ≤ y ≤ 1.46 на плоскости пульта. Размер цели касания ≥ 0.09 м; маховики — радиус ≥ 0.16 м.
Пост может иметь дополнительные виды (крупный план): `engine.setCameraPose(pose, seconds)`.

## 5. Движок (`web/src/engine`) — контракт

```js
import { createEngine } from './engine/index.js';
const engine = await createEngine(canvas, { debug });   // ждёт загрузки шрифта
engine.THREE                       // пространство имён three
engine.scene, engine.camera, engine.renderer
engine.mat, engine.ui, engine.audio, engine.input   // см. ниже
engine.addStation(station)         // порядок добавления = порядок по кольцу
engine.gotoStation(id, { instant })// перелёт камеры (~0.7 с), вызывает onLeave/onEnter
engine.current                     // id текущего поста
engine.setCameraPose(pose|null, seconds) // доп. вид в локальных координатах текущего поста; null — вернуть основной
engine.onFrame(fn)                 // fn(dt, time) каждый кадр
engine.on('station', fn)           // (id) — после смены поста
engine.start() / engine.stop()
engine.shake(amount, seconds)      // тряска камеры (выстрел)
```

Пост — объект:
```js
{ id, title,                      // 'plot', 'ПЛАНШЕТ'
  group,                          // THREE.Group в локальных координатах
  camera: { position, target, fov },
  update(dt, time) {},            // вызывается каждый кадр (и для неактивных, но видимых)
  onEnter() {}, onLeave() {} }
```
Пост создаётся фабрикой `createXxxStation(ctx)`, где `ctx = { engine, THREE, ui, mat, audio, game }`.
Движок скрывает посты, не соседние с текущим, и обрабатывает касания только у текущего.

### 5.1 Ввод
```js
engine.input.add(object3D, { onTap(e), onDown(e), onDrag(e), onUp(e) }) → remove()
// e = { x, y (CSS px), dx, dy (px с прошлого события), ray (THREE.Ray, мир), point (THREE.Vector3 пересечения, мир), object }
engine.input.planePoint(e, planeNormalWorld, planePointWorld) → Vector3|null   // пересечение луча с плоскостью
```
Свайп по пустому месту влево/вправо (> 70 px, быстрый) — переход к соседнему посту (событие отдаётся оболочке:
`engine.on('swipe', dir => …)`, dir = −1/+1). Мышь поддерживается (для отладки на ПК).

### 5.2 Материалы `engine.mat`
`paint(hex, {wear=0.5})`, `steel`, `darkSteel`, `nickel`, `bakelite`, `ivory`, `copper`, `rubber`, `glass`,
`ochre` (эмаль маховиков), `emissive(hex, intensity)`, `floor`, `wall`. Одинаковые вызовы возвращают один и тот же материал (кэш).

### 5.3 Органы управления `engine.ui`
Каждая фабрика возвращает объект с полем `object3D` (ставится в `group` поста). По умолчанию элемент «смотрит» в `+Z`,
начало координат — в центре его основания на панели.

| Фабрика | Параметры | API |
|---|---|---|
| `panel({w,h,d,color,rivets,bevel})` | корпус пульта: коробка со скруглённой фаской и заклёпками по периметру лицевой грани | `object3D` |
| `plate(text,{w,h,style,size})` | шильдик, `style: 'black'|'ivory'|'red'|'ochre'`; многострочный текст через `\n` | `setText(t)` |
| `handwheel({radius,spokes,color,knob,onTurn,onStart,onEnd})` | маховик; игрок крутит круговым движением пальца. `onTurn(deltaRad)` — приращение угла (по часовой для игрока = `+`) | `angle`, `spin(deltaRad)` (повернуть визуально без события) |
| `drumCounter({digits,decimals,unit,digitH,signed})` | барабанный счётчик (одометр): цифры прокручиваются плавно, оправа, стекло | `setValue(v,{instant})`, `value` |
| `lamp({color,radius,label})` | сигнальная лампа с ореолом | `set(false|true|'blink')` |
| `lever({length,color,mode,labels,onPull,onChange})` | рычаг: `mode:'momentary'` (потянул вниз — `onPull()`, возврат пружиной) или `'toggle'` (два положения, `onChange(on)`) | `set(on)`, `on` |
| `slewLever({length,onInput})` | подпружиненный рычаг-джойстик влево/вправо: `onInput(v)` где v ∈ [−1,1] каждый кадр, пока удерживается; при отпускании возвращается в 0 | `value` |
| `rotarySelector({positions,labels,radius,value,onChange})` | галетный переключатель с фиксацией; перетаскиванием или касанием подписи | `set(i)`, `value` |
| `gauge({radius,min,max,label,unit,zones,majorStep,minorStep})` | стрелочный прибор, стрелка с демпфированием | `setValue(v)`, `setBug(v|null)` (метка-указатель задания) |
| `pushButton({radius,color,label,onPress,hold})` | кнопка; при `hold:true` — `onPress` повторяется, пока нажата | `setLit(b)` |
| `toggle({labels:[a,b],value,onChange})` | тумблер на два положения | `set(i)`, `value` |
| `cover({w,h,onChange})` | откидная предохранительная крышка (красная) над элементом | `open`, `set(b)` |
| `pipe(points,radius,material)`, `cageLamp()`, `rivetRow(...)`, `cable(...)` | декор | `object3D` |

Все подвижные элементы анимируются сами (подписаны на `engine.onFrame`) и издают звук через `engine.audio`.

### 5.4 Звук `engine.audio` (WebAudio, синтез, без файлов)
`tick()`, `ratchet()`, `clunk()`, `leverPull()`, `switchFlip()`, `buzz()` (отказ), `servo(level 0..1)` (гул привода),
`hoist()`, `ram()`, `breech()`, `fire()`, `impactFar()`, `radio()`, `alarm(on)`, `ambient(on)`, `setMuted(b)`.
Контекст создаётся при первом касании.

## 6. Игровая логика (`web/src/game`) — контракт

> Логика уже реализована и покрыта тестами. **Точный фактический API — в `web/src/game/README.md`**; ниже — обзор.

Чистый JS без DOM/THREE. Единицы: расстояния — **км**, углы — **градусы**, время — с.
Пеленг: 0° — север, по часовой, 0…360. Карта 20×20 км: `x` — на восток, `y` — на север.

```js
import { createGame } from './game/index.js';
const game = createGame({ storage });      // storage: {get(key), set(key,val)} (localStorage-обёртка) или null
game.state                                 // см. ниже; менять ТОЛЬКО методами game
game.on(event, fn) → off()                 // события
game.update(dt)                            // вызывать каждый кадр (сек реального времени; сама учитывает паузу)
game.campaign                              // [{ id, name, brief, ... }]
game.save                                  // { unlocked, stars: [], difficulty }
```

### 6.1 Состояние
```js
state = {
  phase: 'menu' | 'briefing' | 'playing' | 'won' | 'lost',
  paused: false,
  difficulty: 0 | 1,              // 0 «Курсант», 1 «Командир»
  time: 0,                        // с от начала задания
  mission: { id, index, name, brief, battery: {x,y}, mapSeed, tutorial: bool },
  integrity: 100,                 // прочность батареи, 0 → поражение
  shells: { he: 10, ap: 6 },      // остаток снарядов
  targets: [{
    id, label: 'ЦЕЛЬ 1', name: 'Баржа', kind,          // kind: 'barge'|'battery'|'destroyer'|...
    armored: bool, hp, maxHp, radius,                   // radius — км
    alive: true, escaped: false,
    reported: { x, y, course, speed, time } | null,      // последнее донесение разведки (км, °, узлы→км/ч в тексте)
    moving: bool,
    // истинные x, y, course, speed — есть в объекте, но постам их показывать НЕЛЬЗЯ
  }],
  activeTarget: id,
  plot: {
    pins: { [targetId]: { x, y } },          // фишки, поставленные игроком
    alidade: { bearing, range },             // текущее положение алидады и движка (° / км)
    recorded: { [targetId]: { bearing, range, time } }   // записанные замеры
  },
  computer: { range, charge, elevation|null, tof|null, stale: bool },  // stale — входы изменились после расчёта
  turret: { bearing, brake: bool, elevation },
  breech: { open, shell: null|'he'|'ap', rammed: bool, charges: 0..6, busy: null | { kind, t, dur } },
  fire: { armed: bool },
  flight: [{ id, t, tof }],                  // снаряды в полёте (t — прошло секунд)
  radio: [{ time, from, text, kind }],       // журнал радиообмена (последние сверху не обязаны быть — порядок хронологический)
  lastReport: null | { targetId, over, right, text },   // последнее отклонение (м; over>0 — перелёт, right>0 — вправо)
  checklist: { measured, computed, loaded, traversed, elevated, armed },  // производное, для подсказок HUD
  shots: 0,
}
```

### 6.2 Действия (все возвращают `{ ok: true }` или `{ ok: false, reason: '…по-русски…' }`; при отказе шлют событие `denied`)
```js
game.startMission(index) / game.startSkirmish() / game.begin() /*briefing→playing*/ / game.pause(b) / game.quit()
game.selectTarget(id)
game.setPin(targetId, x, y)                // км, округляется до 0.01
game.setAlidade({ bearing, range })        // bearing до 0.1°, range до 0.01 км
game.recordMeasurement()                   // записать показания алидады для активной цели
game.setComputerRange(km)                  // 0.01…22.00
game.setComputerCharge(n)                  // 1…6
game.chargeStates()                        // → ['ok'|'out', ×6] для текущей дальности вычислителя
game.compute()                             // → { ok, elevation, tof } | { ok:false, reason }
game.setBrake(b)
game.rotateTurret(deltaDeg)                // отказ, если стопор стоит
game.elevate(deltaDeg)                     // −2…45°, шаг 0.01
game.openBreech() / game.closeBreech()     // открыть можно только при elevation ≤ LOAD_ANGLE (3°)
game.hoistShell('he'|'ap')                 // подать снаряд на лоток (занимает время, breech.busy)
game.ramShell()                            // дослать
game.addCharge() / game.removeCharge()     // по одному картузу
game.unload()                              // разрядить (вернуть снаряд и заряды)
game.arm(b)
game.fire()                                // выстрел фактическими bearing/elevation/charges
game.solve(rangeKm, charge)                // чистая функция: { ok, elevation, tof }
game.chargeRange(n)                        // { min, max } км
```
Константы: `game.C = { LOAD_ANGLE: 3, EL_MIN: -2, EL_MAX: 45, CHARGES: 6, MAP: 20 }`.

### 6.3 События
`'state'` (любое изменение; дешёвое, можно перечитывать `game.state`), `'radio' (msg)`, `'denied' ({action, reason})`,
`'computed' (res)`, `'breech' (state.breech)` (каждая смена фазы заряжания), `'fired' ({tof, shell, charges})`,
`'impact' ({report, hits})`, `'targetDestroyed' (target)`, `'batteryHit' ({damage})`, `'phase' (phase)`,
`'missionEnd' ({ won, stars, reason, stats })`.

Посты **не хранят игровую логику**: они показывают `game.state` и вызывают действия. Анимации длительных операций
берут прогресс из `state.breech.busy`.

## 7. Посты — содержание

Общее: в верхней части каждого пульта — шильдик с названием поста. Числа с других постов игрок переносит сам
(они записаны в блокноте HUD), но на постах наводки есть **репитеры** — маленькие счётчики «ЗАДАНО» с записанным
пеленгом/вычисленным углом.

### 7.1 ПЛАНШЕТ (`plot`)
Стол с картой 20×20 км (вид сверху под углом, камера смотрит вниз ~65°; есть крупный план). Карта — canvas-текстура:
море, береговая линия, сетка 1 км с оцифровкой по краям (X и Y, 00…20), батарея отмечена знаком.
- Фишки целей: у каждой сообщённой цели — фишка; игрок перетаскивает её по карте, рядом счётчики **X** и **Y** (км, 0.01)
  показывают положение выбранной фишки; четыре кнопки-стрелки точной подвижки (±0.01 км, с автоповтором).
- Алидада: линейка с осью на батарее. Поворот — перетаскиванием линейки или маховиком «ПЕЛЕНГ» (точно, 0.1°);
  ползун-визир вдоль линейки — перетаскиванием или маховиком «ДАЛЬНОСТЬ» (0.01 км). Счётчики **ПЕЛЕНГ** (000.0°) и
  **ДАЛЬНОСТЬ** (00.00 км).
- На «Курсанте» при подведении визира к фишке ближе 0.15 км он примагничивается, горит лампа «СОВМЕЩЕНО».
- Кнопка «ЗАПИСАТЬ» → `game.recordMeasurement()`.
- Переключение цели — касанием фишки.

### 7.2 ВЫЧИСЛИТЕЛЬ (`computer`)
Механический баллистический вычислитель: маховик «ДАЛЬНОСТЬ» + тумблер «ГРУБО/ТОЧНО» → счётчик дальности;
галетник «ЗАРЯД» 1…6 с шестью лампами (зелёная — достаёт, красная — нет); рычаг «ВЫЧИСЛИТЬ» →
счётчик «УГОЛ ВОЗВЫШЕНИЯ» (00.00°) и «ВРЕМЯ ПОЛЁТА» (с); лампа «УСТАРЕЛО», если входы изменены после расчёта;
при отказе — зуммер и красная лампа «ВНЕ ДАЛЬНОСТИ». Декор: вращающиеся при расчёте шестерни/кулачки за стеклом.

### 7.3 ЗАРЯЖАНИЕ (`loading`)
Казённая часть орудия (большой затвор), лоток, элеваторы. Органы: рычаг затвора (открыть/закрыть), тумблер типа снаряда
ОФ/ББ и кнопка «ПОДАТЬ СНАРЯД», рычаг «ДОСЛАТЬ», кнопки «ЗАРЯД +» / «ЗАРЯД −», счётчик «ЗАРЯДОВ», кнопка «РАЗРЯДИТЬ»,
лампы «УГОЛ ЗАРЯЖАНИЯ», «ЗАТВОР ЗАКРЫТ», счётчики остатка ОФ/ББ. Анимации: затвор, снаряд на лотке, досылатель, картузы.

### 7.4 ПОВОРОТ (`traverse`)
Рычаг стопора (тумблер-рычаг), рычаг привода (`slewLever`, до 12°/с), маховик точной наводки (1° на оборот),
счётчик «ПЕЛЕНГ БАШНИ» (000.00°), репитер «ЗАДАНО» (записанный пеленг активной цели), круговой указатель курса
(вращающаяся картушка), прибор давления гидравлики (оживает при работе привода).

### 7.5 ПОДЪЁМ (`elevation`)
Большой маховик (тумблер ГРУБО 10°/об. / ТОЧНО 0.5°/об.), счётчик «УГОЛ СТВОЛА» (00.00°), репитер «ЗАДАНО»
(вычисленный угол), секторный указатель угла со стрелкой и меткой задания, прибор рассогласования (±),
лампа «УГОЛ ЗАРЯЖАНИЯ», модель качающейся части (ствол-индикатор).

### 7.6 ОГОНЬ (`fire`)
Табло готовности: лампы «СНАРЯД», «ЗАРЯД», «ЗАТВОР», «СТОПОР», «ЦЕПЬ». Тумблер «ЦЕПЬ СТРЕЛЬБЫ» под красной крышкой,
спусковой рычаг. Репитеры пеленга/угла/заряда. Секундомер полёта снаряда (стрелочный, обратный отсчёт до разрыва).
Телеграфный аппарат: лента с последним докладом корректировщика. Смотровая щель (вспышка при выстреле).

## 8. Оболочка (`web/src/ui`, `web/static`)
DOM поверх canvas: верхняя панель (время, прочность, снаряды, пауза, блокнот), нижняя — шесть кнопок постов
с отметками выполненных шагов, строка последнего радиосообщения; блокнот (донесения, замеры, расчёт, журнал),
меню, выбор задания и сложности, брифинг, итоги. Обучение в первом задании — подсказка «что делать дальше»
по `state.checklist`.

### 8.1 Кто за что отвечает (чтобы не было двойных эффектов)
Оболочка (`web/src/ui/shell.js`, уже написана) сама делает **общие** эффекты по событиям игры:
- `fired` → `audio.fire()`, тряска камеры, вспышка экрана, вибрация;
- `impact` → `audio.impactFar()`; `batteryHit` → удар, красная вспышка, тряска;
- `radio` → `audio.radio()` и строка сообщения; `denied` → `audio.buzz()` и красная плашка с причиной отказа.

Посты эти звуки/эффекты **не дублируют**. Пост отвечает только за свои механические звуки (щелчки, трещотки,
привод, досылатель, затвор) и локальные визуальные реакции (лампы, откат, вспышка в щели).

Оболочка показывает внизу строку-памятку (записанный пеленг/дальность, заряд, угол) и подсказку следующего шага;
верх экрана (40 px) и низ (56 px) заняты панелями — см. §4 «Зона управления».

Точка входа `web/src/main.js` ожидает экспорты: `createPlotStation`, `createComputerStation`, `createLoadingStation`,
`createTraverseStation`, `createElevationStation`, `createFireStation` из `web/src/stations/<id>.js`.
