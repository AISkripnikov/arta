# АРТА — Огневая позиция

Игра для Android про стрельбу с закрытой огневой позиции. Цель не видна: её координаты
сообщает наблюдатель по рации, а игрок сам рассчитывает установки и наводит орудие.

## Что есть в игре

- **Карта 12×12 км** с координатной сеткой, рельефом (горизонтали), линейкой, метками и кругом дальностей/азимутов.
- **Таблицы стрельбы** для четырёх зарядов: прицел, время полёта, поправки на превышение цели, деривацию и ветер.
  Таблицы строятся той же баллистической моделью (сопротивление воздуха, ветер, рельеф), что и полёт снаряда.
- **Орудие**: угломер и прицел в делениях угломера (60-00), выбор заряда, время на наводку и заряжание.
- **Наблюдатель**: доклады «перелёт / недолёт, правее / левее» — от линии стрельбы или от линии «НП → цель».
- **Вычислитель**: огневой планшет, калькулятор (sin/cos/atan в делениях угломера), блокнот.
- **Кампания из 8 задач** (высоты, вынесенный НП, ветер, полярные координаты, движущаяся колонна,
  контрбатарейная борьба) и свободный бой со случайными задачами.
- **Три уровня сложности**: от линейки, которая сама показывает дальность и азимут, до полностью ручного расчёта.

## Установка

Готовый APK: [`dist/ARTA.apk`](dist/ARTA.apk). Скопируйте на телефон и установите
(потребуется разрешить установку из неизвестных источников). Android 7.0+.

## Сборка

Нужны JDK 17+ и Android SDK (platform 34, build-tools 34). Путь к SDK — в `local.properties` (`sdk.dir=...`)
или в переменной `ANDROID_HOME`.

```bash
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/`. Он подписан отладочным ключом — для публикации в магазине
нужен собственный ключ подписи.

## Устройство проекта

Приложение — тонкая Android-обёртка (`MainActivity` с WebView), сама игра написана на HTML5/JS
и лежит в `app/src/main/assets/www`:

| Файл | Назначение |
| --- | --- |
| `js/ballistics.js` | модель полёта снаряда и генерация таблиц стрельбы |
| `js/terrain.js` | процедурная местность и подложка карты |
| `js/missions.js` | кампания и генератор задач |
| `js/calc.js` | разбор выражений калькулятора |
| `js/game.js` | игровой цикл, карта, орудие, рация, интерфейс |

Игру можно открыть и в обычном браузере: `app/src/main/assets/www/index.html`.
