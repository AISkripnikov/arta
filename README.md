# АРТА: Башня

Игра для Android — симулятор тяжёлой башни береговой батареи. Цель не видна: разведка сообщает координаты,
а игрок сам проходит всю процедуру выстрела на шести механических постах — и ещё на двух следит за морем
и небом:

| Пост | Что делает игрок |
| --- | --- |
| **Планшет** | ставит фишку цели на карту, наводит алидаду, считывает пеленг и дальность |
| **Вычислитель** | набирает дальность маховиком, выбирает заряд, рычагом получает угол возвышения |
| **Заряжание** | открывает затвор, галетником выбирает и подаёт снаряд (ОФ, ББ, ОСВ, ДЫМ, ШРП), досылает, подаёт заряды |
| **Поворот** | снимает стопор, разворачивает башню на пеленг |
| **Подъём** | маховиком поднимает ствол на вычисленный угол |
| **Огонь** | проверяет лампы готовности, взводит цепь стрельбы, дёргает спуск |
| **Наблюдение** | стереотруба ×4/×10 с сеткой в градусах: корабли, свои разрывы, вспышки, осветительные снаряды, самолёты; пеленг трубы наносится на планшет |
| **Зенитка** | ведёт спаренный автомат по небу, держит самолёт в кольце прицела, следит за перегревом ствола |

После разрыва корректировщик докладывает отклонение — игрок вносит поправки; на карте планшета видны
трасса летящего снаряда и круги разрывов.

- **Кампания из 36 заданий** в пяти частях: береговая оборона, контрбатарейная борьба, острова в огне,
  «Ночь и туман», «Конвой».
- **Свой глаз**: если разрыв лёг в поле зрения трубы, расчёт сразу докладывает «НАБЛЮДАЮ: правее на 0,4°,
  перелёт» — днём, а ночью по освещённой цели; когда корректировщик слеп, это единственная поправка.
- **Корабли-модели**: у каждой цели свой силуэт и курс; подбитые горят, кренятся и 18 секунд уходят под воду —
  в смотровой щели и в трубе.
- **Свои силы**: конвои и сторожевые катера всегда отмечены на планшете. Разрыв ближе 250 м от своего —
  попадание; потопленный свой стоит звезду, потерянный целиком конвой — задания. Транспорт под огнём
  прикрывают дымовым снарядом.
- **Налёты авиации**: за 10 секунд радист кричит «ВОЗДУХ!»; сбитый самолёт — опыт, прорвавшийся — бомба по батарее.
- **Расчёт**: наводчик, заряжающий и радист устают и получают ранения — их работа замедляется; аптечка
  возвращает бойца в строй.
- **Снабжение**: за каждые 150 опыта — очко; шесть улучшений башни по три уровня (элеватор, дальномер,
  второй корректировщик, броня, погреб, ремонтная партия), сброс с полным возвратом.
- **Задание дня**: одно на всех по дате, со счётом и лучшим результатом.
- **Сохранение боя**: бой запоминается при сворачивании, выходе с сохранением и каждые 15 секунд —
  «ПРОДОЛЖИТЬ БОЙ» в меню. **Настройки**: чувствительность маховиков, размер надписей, режим для левши, вибрация.
- **Пять типов снарядов**: фугасный, бронебойный, осветительный (минуту освещает круг 1,5 км), дымовой
  (завеса в 1–4 км от батареи сбивает прицел противнику) и шрапнель (по десанту).
- **Ночь, туман и шторм**: ночью штаб даёт только квадрат 2×2 км — цель подсвечивают осветительным снарядом
  или засекают по вспышке; в тумане донесения реже и грубее; в шторм ветер меняется по ходу боя.
- **«Вилка»** — залп двумя стволами с разносом ±150 м по дальности; **вид из смотровой щели** на посту «Огонь»:
  море, вспышка выстрела, далёкие разрывы.
- **Звания расчёта** (опыт за победы ускоряет заряжание и ремонт), режим **«Оборона»** — бесконечные волны
  с рекордом, **«Разбор боя»** — карта с путями целей и всеми разрывами.
- **Звукометрия**: скрытые батареи засекаются по пеленгам двух постов на берегу; на «Командире» линии
  пеленгов игрок прокладывает сам, переставляя ось алидады на пост.
- **Кочующие батареи**, цели волнами, движущиеся и бронированные цели, ответный огонь с предупреждающим свистом.
- **Ветер**: вычислитель учитывает его в угле возвышения и выдаёт поправку пеленга.
- **Повреждения башни** (привод, элеватор, освещение) и ремонт, **огонь очередью** 1–3 выстрела.
- **Обучение** с подсветкой нужного органа управления, **рекорды** по каждому заданию, две сложности.
- **Звук без файлов**: всё синтезируется — выстрел с суб-басом и звоном брони, механизмы, эхо стальной башни
  и далёкие разрывы над морем, фон по посту и погоде, сирена и зенитка в стереопанораме, музыка в меню.
- **Графика по уровням качества** («АВТО» / высокое / среднее / экономное): тени от ламп, свечение, постобработка,
  крашеный металл с износом, живое море и небо со временем суток; «АВТО» само снижает уровень, если телефон не успевает.

## Установка и обновления

Готовый APK: [`dist/ARTA.apk`](dist/ARTA.apk) (Android 7.0+, альбомная ориентация).
Игра **обновляется сама**: приложение скачивает свежую версию из каталога [`ota/`](ota) этого репозитория,
проверяет SHA-256 каждого файла и переключается на неё; встроенная в APK версия остаётся запасной.

Выпуск обновления: добавьте в начало `web/src/changelog.js` запись с id на единицу больше и кратким списком
изменений — игроки увидят его в окне «ЧТО НОВОГО» при следующем запуске. Затем:

```bash
cd web && node build.mjs && node build.mjs --publish
```

```bash
git add -A && git commit -m "Обновление игры" && git push
```

Установленные приложения получат его в течение нескольких минут (кэш GitHub — до 5 минут).

## Сборка

```bash
cd web && npm install && npm test && node build.mjs
```

```bash
./gradlew assembleRelease
```

Нужны Node 20+, JDK 17+ и Android SDK (platform 34). APK подписывается отладочным ключом.

## Устройство

- `web/src/game` — игровая логика без графики (баллистика, задания, состояние башни), тесты в `web/test`.
- `web/src/engine` — 3D-движок на three.js: комната башни, материалы, ввод, звук, органы управления
  (маховики, барабанные счётчики, рычаги, лампы, приборы). Справка — `web/src/engine/README.md`.
- `web/src/stations` — восемь постов (и `ships.js` — модели кораблей и самолёта); `web/src/ui` — меню, HUD, блокнот.
- `web/tools` — тесты управления постов (`test-*.cjs`), звука (`test-audio.cjs`), качества (`test-quality.cjs`),
  сквозная проверка (`e2e.cjs --tier low|mid|high`), замер кадра (`perf.cjs`), обзорные снимки (`tour.cjs`), манифест обновлений.
- `app/` — Android-обёртка (WebView) и обновление «по воздуху» (`OtaCore`, `Updater`).
- `docs/DESIGN.md` — проектный документ.
